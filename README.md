# 🎮 HeartFall

### A 2D Platformer built with Unity & C#

> Fight your way through dangerous levels, avoid traps, defeat enemies, collect hearts, and reach the next room.

---

## 🕹️ About the Game

**HeartFall** is a 2D platformer developed in Unity using C#.

The game focuses on platforming, combat, enemy interactions, traps, collectibles, and room-based progression.

The project was built to explore core game development systems and bring them together into a playable experience.
